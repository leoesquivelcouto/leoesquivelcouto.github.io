Gestão de abonos e atestados

em implantação

Sistema web para uma escola registrar e acompanhar abonos e atestados de professores, com login, banco de dados e um dashboard para a coordenação.

Problema

A escola precisava de um lugar único para registrar, consultar e acompanhar abonos e atestados dos professores.

Decisões

Login com controle de acesso, banco de dados relacional e um dashboard pensado para a coordenação.

Resultado

Em implantação na escola, com usuários reais.

  • Banco de dados relacional
  • Autenticação
  • Dashboard

Código privado: os dados pertencem à escola.

rumo

em desenvolvimento

Rastreador de candidaturas que calcula a compatibilidade de cada vaga com as minhas competências e mostra o que estudar a seguir, com base no que as vagas mais pedem.

Problema

Vagas espalhadas em abas e planilhas, prazos perdidos e nenhuma visão dos requisitos que se repetem.

Decisões

FastAPI com validação em Pydantic; SQL escrito à mão, sem ORM; pontuação explicável em vez de IA; tudo local.

Resultado

Versão local funcionando, com 36 testes e CI. Publicação no GitHub em etapas, commit a commit.

  • FastAPI
  • SQLite

  • pytest
  • Docker
  • GitHub Actions
